# WorkLog Pro

Version i përditësuar i aplikacionit WorkLog / Raport Mujor.

## Ndryshimet kryesore

- Backup JSON për të gjitha muajt dhe lokacionet.
- Import JSON për rikthim të të dhënave.
- Snapshot automatik lokal pas ruajtjes.
- Orë pune me hapa 0.5, për shembull 8.5 orë.
- Mundësi regjistrimi edhe për fundjavë.
- PDF mujor më profesional me statistika, tabela dhe përmbledhje lokacionesh.
- Manifest PWA i pastruar për përdorim më të mirë në telefon.

## Shënim

Të dhënat ruhen lokalisht në pajisje. Për siguri reale, përdor rregullisht butonin Backup nga Settings.
