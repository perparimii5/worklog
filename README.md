# WorkLog Pro v3

Version i përditësuar i aplikacionit WorkLog / Raport Mujor.

## Shtesat kryesore

- Orë fleksibile: 0h deri 24h me hapa 0.5h.
- Quick buttons për 4h, 6h, 7h, 8h, 8.5h, 9h, 10h, 12h etj.
- Llogaritje automatike nga ora e fillimit, ora e mbarimit dhe pauza.
- Overtime / minus hours sipas kontratës javore.
- Salary estimator me CHF/orë.
- Fushë për punë/projekt/kompani.
- Foto provë për ditën e punës.
- Voice note në shënime, kur browseri e lejon.
- Calendar view me ngjyra sipas tipit të ditës.
- PDF më profesional me overtime, pagë bruto të përafërt, orar dhe punë/lokacion.
- Backup/import JSON dhe snapshot automatik lokal.

## Shënim

Të dhënat ruhen lokalisht në pajisje. Për siguri reale, përdor rregullisht Backup JSON. Cloud sync/login kërkojnë version me backend si Supabase/Firebase.
